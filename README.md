## 收录说明

- Jacobson《基础代数》两卷收录中英文勘误。《拓扑学引论》第 2 版收录中文勘误。
- GTM 4、76、84 的解答目前只有 PDF。GTM 84 的习题 13.23 和 14.16 尚未完成。
- GTM 26 的习题 2.1.27、3.3.6 仍有未解分问。GTM 246 的习题 2.12.61 只给出部分结果。
- GTM 256 收录 144 道中文题面和 125 道新编解答，另 19 道在相应题号下指向原书书后选解。
- Bosch《代数学》收录 296 道中文题面和 211 道新编解答，另 85 道在相应题号下指向原书附录。
- 《结合代数表示论基础》第 1 卷收录 165 个题号，其中 IX.12 因编写所据版本缺少原书第 403 页而暂缺解答。
- 编译方法见各源码包内的说明。部分 PDF 指向配套原书或译本的链接需要读者自行提供相应文件。
