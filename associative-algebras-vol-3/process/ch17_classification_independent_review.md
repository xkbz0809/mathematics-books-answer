## 理论

1. 欧几里得倾斜模不能全正则：各非齐次管可相容石模数至多 r−1，总和 n−2，小于 n。齐次管无石模。由此归一化确有后投射或前内射起点。
2. 对后投射最小层作 τ 归一化有效。所有过程对象在施行 τ 前无投射项；遗传性确保非投射不可分解模到投射模的 Hom 为零，其对偶确保目标侧不出现因经过内射而丢失的态射。因此保持普通 End 及复合，而不只保持稳定 End。无后投射情形由向量空间对偶在 H^op 上覆盖，最终取 End 的反代数。
3. 与 P_i 相容的非投射项 X 必须满足 (dim τX)_i=0；这一条件不是经验截断。各型两个定向的 Coxeter 周期幂 N 满足 N²=0，每一个周期余数中的轨道增量都是 δ 的严格正倍数，故超过一周期的对应向量全忠诚。正文给出的有限层范围覆盖所有候选。
4. 正则候选的有限盒 0≤d≤δ、亏量零、q(d)=1 恰给出拟长小于秩的全部管石模；其唯一性与普通 Hom 的管公式均对任意代数闭域有效。
5. 枚举的是 n 项无重数 Ext 消失集，遗传倾斜判别给出充分性。反向输入的维数向量经对偶保持不变，因此表中采用同一固定 H 的 M(d) 记法是正确的。
6. Cartan 同时置换仅作预筛。每组实际箭到路径映射已经验证；不同组由 Cartan 不变量严格分离，故不存在把相同 Cartan 误当同构的逻辑跳步。
7. 特征审计程序覆盖实际 Hom 方程、rad²、路径核与商维数消元以及同构箭层行列式；唯一例外素数为 2。特征二文件另构造 Schur 实根表示（End=F2 保证在代数闭包仍绝对不可分解），重新核对全部兼容 Hom 与 End 和同构。该方式弥补了单纯 Q 上计算不能涵盖任意特征的问题。
